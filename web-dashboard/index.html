BATTERY AWARENESS

100% Charge Guardian

Monitor battery level and receive reminders when the battery reaches 100% or falls below 15%.

Rules

  • At 100% while plugged in: full-charge reminder.
  • Below 15% and unplugged: connect-charger warning.

Optional backend

Run the FastAPI server and open API documentation on the same computer.

Note: This dashboard is informational. It does not read device battery status by itself and cannot lock a phone or laptop.
